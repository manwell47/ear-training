## 🇪🇸 Español

Una plataforma avanzada de entrenamiento auditivo y ecualización paramétrica diseñada para ingenieros de sonido, productores y estudiantes de audio.

🔗 **[Acceder a la Web App (GitHub Pages)](https://manwell47.github.io/ear-training/)** 
*(Nota: La versión web puede estar limitada. Para la experiencia multitrack completa con assets de alta calidad, clona el repositorio).*

### 🚀 Características Principales
- **Simulador de Ecualización Quirúrgica**: Interfaz hiperrealista similar a plugins profesionales.
- **Director Pedagógico**: Evalúa tu progreso con escenarios reales de mezcla (Ej: "Atenuar caja nasal", "Cortar sibilancia").
- **Motor de Feedback Acústico**: Te corrige como un ingeniero senior explicándote el efecto psicoacústico.
- **Sistema RPG de Dificultad**: Progresión desde "Tiracables" hasta "Mastering Engineer".
- **Renderizado VST-Fidelity**: Espectrogramas fluidos y rellenado volumétrico con balística temporal precisa (RMS/EMA).

### 🛠 Instalación y Uso (Local)
1. Clona el repositorio: `git clone https://github.com/manwell47/ear-training.git`
2. Instala Node.js y arranca el servidor: `node dev-server.js`
3. Abre tu navegador en [http://localhost:3000](http://localhost:3000).

## 🇬🇧 English

An advanced ear training and parametric equalization platform designed for sound engineers, producers, and audio students.

🔗 **[Access the Web App (GitHub Pages)](https://manwell47.github.io/ear-training/)**
*(Note: The web version may be limited. For the full multitrack experience with HQ assets, clone the repo).*

### 🚀 Key Features
- **Surgical EQ Simulator**: Hyper-realistic interface similar to professional plugins.
- **Pedagogical Director**: Evaluates your progress with real mixing scenarios (e.g., "Cut boxy snare", "Reduce sibilance").
- **Acoustic Feedback Engine**: Corrects you like a senior engineer, explaining the psychoacoustic effect.
- **RPG Difficulty System**: Progression from "Cable Guy" to "Mastering Engineer".
- **VST-Fidelity Rendering**: Fluid spectrograms and volumetric fill with precise temporal ballistics (RMS/EMA).

### 🛠 Installation & Usage (Local)
1. Clone the repo: `git clone https://github.com/manwell47/ear-training.git`
2. Run the server: `node dev-server.js`
3. Open [http://localhost:3000](http://localhost:3000) in your browser.
