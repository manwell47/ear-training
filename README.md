# Ear Training Pro 🎧

Una plataforma avanzada de entrenamiento auditivo y ecualización paramétrica diseñada para ingenieros de sonido, productores y estudiantes de audio.

## 🚀 Características Principales

- **Simulador de Ecualización Quirúrgica**: Interfaz hiperrealista similar a plugins profesionales (como FabFilter Pro-Q).
- **Director Pedagógico**: Evalúa tu progreso con escenarios reales de mezcla (Ej: "Atenuar caja nasal", "Cortar sibilancia").
- **Motor de Feedback Acústico**: Te corrige como un ingeniero senior explicándote el efecto psicoacústico de cada banda.
- **Sistema RPG de Dificultad**: Progresión desde "Tiracables" hasta "Mastering Engineer", evaluando precisión en frecuencia, ganancia y topología del filtro.
- **Renderizado VST-Fidelity**: Espectrogramas fluidos y rellenado volumétrico con balística temporal precisa (RMS/EMA).

## 🛠 Instalación y Uso

1. Clona el repositorio:
   ```bash
   git clone https://github.com/manwell47/ear-training.git
   ```
2. Instala las dependencias y arranca el servidor local:
   ```bash
   node dev-server.js
   ```
3. Abre tu navegador en `http://localhost:3000`.
